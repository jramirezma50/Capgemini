🚀 Capgemini

Proyecto de Infraestructura con Terraform

¿Qué es este proyecto?

Este es un proyecto completo de Terraform diseñado para gestionar infraestructura en AWS de manera profesional y escalable. Incluye configuraciones para múltiples ambientes y mejores prácticas de DevOps.

✨ Características Principales

Multi-Ambiente

Configuraciones separadas para dev, staging y producción

VPC Completa

Red virtual con subnets públicas y privadas

EC2 Instances

Instancias escalables con monitoreo integrado

Security Groups

Configuración segura de firewalls

🛠️ Stack Tecnológico

  • Terraform - Infrastructure as Code
  • AWS - Proveedor de nube
  • EC2 - Instancias de computación
  • VPC - Red privada virtual
  • CloudWatch - Monitoreo y logs
  • Docker - Containerización de aplicaciones

📋 Estructura del Proyecto

├── provider.tf # Configuración del proveedor AWS
├── main.tf # Recursos principales
├── variables.tf # Variables de entrada
├── outputs.tf # Valores de salida
├── environments/ # Configuraciones por ambiente
│ ├── dev/ # Desarrollo
│ ├── staging/ # Pruebas
│ └── prod/ # Producción
├── scripts/ # Scripts de usuario
├── Makefile # Comandos útiles
└── .gitignore # Archivos excluidos de git

🚀 Comandos Útiles

# Inicializar Terraform
make init

# Planificar cambios
make plan ENVIRONMENT=dev

# Aplicar cambios
make apply ENVIRONMENT=dev

# Destruir infraestructura
make destroy ENVIRONMENT=dev

# Validar configuración
make validate

📊 Ambientes Disponibles

  • Development (dev): t3.micro, 1 instancia
  • Staging: t3.small, 2 instancias
  • Production (prod): t3.medium, 3 instancias

🐳 Docker & Contenedores

Este proyecto ahora está completamente containerizado. Puedes ejecutar la infraestructura completa usando Docker y Docker Compose.

# Compilar imagen Docker
docker build -t capgemini-web .

# Ejecutar con Docker Compose
docker-compose up -d

# Ver logs
docker-compose logs -f

# Detener servicios
docker-compose down

📡 Puertos Disponibles

  • Puerto 8000: Aplicación web principal (Proyecto)
  • Puerto 8001: API de equipo y datos (JSON)
  • Puerto 3996: Servidor Python local (desarrollo)
